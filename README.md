# Machine Learning Projects

A collection of machine learning and deep learning projects covering regression, classification, natural language processing, neural networks, and recommender systems — built while learning and applying core ML concepts with Python.

## Projects

### 🏠 House Price Prediction
**Folder:** `House Price Prediction/`
**Tech:** Python, Scikit-learn, Pandas, NumPy

A linear regression model trained on the USA Housing dataset to predict house prices based on features such as area income, house age, number of rooms, number of bedrooms, and area population. Includes exploratory data analysis (EDA) and feature evaluation to identify the strongest predictors of price.

- `House_prediction.ipynb` — model building, training, and evaluation
- `USA_Housing.csv` — dataset

---

### 📩 NLP — Spam Classification & Text Analysis
**Folder:** `NLP/`
**Tech:** Python, NLTK, Scikit-learn, Text Classification

Two natural language processing tasks:
1. **SMS Spam Classifier** — built using the SMS Spam Collection dataset, applying text preprocessing, tokenization, and vectorization (Bag-of-Words / TF-IDF) to classify messages as spam or ham.
2. **Yelp Review Text Classification** — explored sentiment and review-based classification on the Yelp reviews dataset, covering feature extraction and model evaluation for text data.

- `NLP_Project.ipynb` — spam classification pipeline
- `NLP_with_python.ipynb` — Yelp review text classification
- `smsspamcollection/` — SMS spam dataset
- `yelp.csv` — Yelp reviews dataset

---

### 🧠 Neural Networks with Keras
**Folder:** `Neural_Networks/`
**Tech:** Python, TensorFlow, Keras, Deep Learning

A set of notebooks exploring core deep learning workflows using the Keras API — building, training, and evaluating neural networks for both classification and regression tasks.

- `Keras_basic.ipynb` — fundamentals of building a neural network in Keras
- `Keras Regression.ipynb` — neural network for regression tasks
- `Keras Classification.ipynb` — neural network for classification tasks
- `Keras API Project.ipynb` — end-to-end applied project using the Keras API
- `fake_reg.csv` — dataset used for regression practice
- `my_gem_model.keras` — saved/trained model

---

### 🎬 Movie Recommender System
**Folder:** `Recomender_System_with_python/`
**Tech:** Python, Pandas, Collaborative Filtering

A movie recommendation engine built using collaborative filtering on user ratings data, mapping movie IDs to titles to produce interpretable, real-world-style recommendations.

- `Recomender_system.ipynb` — recommender system implementation
- `Movie_Id_Titles` — lookup file mapping movie IDs to titles
